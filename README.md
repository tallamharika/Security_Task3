## 📝 Project Description

This project focuses on performing **basic web application security testing** on a sample application to identify common security vulnerabilities such as **SQL Injection** and **Cross-Site Scripting (XSS)**.

The testing was conducted on an **intentionally vulnerable demo web application** designed for **learning, research, and ethical security testing purposes**. The objective was to understand real-world security flaws and document their potential impact along with recommended mitigation strategies.

---

## 🎯 Objectives

- Identify common security vulnerabilities in a web application  
- Understand real-world web security risks  
- Practice ethical security testing techniques  
- Document findings with proper evidence  
- Suggest mitigation strategies to reduce security risks  

---

## 🌐 Tested Application

- **Target URL:** https://demo.testfire.net/  
*(Intentionally vulnerable demo application for security training)*

---

## 🔍 Testing Type

- **Manual Web Application Security Testing**

---

## 🧪 Vulnerabilities Tested

1. **SQL Injection (SQLi)**  
2. **Cross-Site Scripting (XSS)**  

---

## 🛠 Tools Used

- **Web Browser:** Google Chrome  
- **Testing Tool:** OWASP ZAP (for vulnerability identification & reporting)  
- **Documentation:** Visual Studio Code  

---

## 📂 Deliverables

- **Security Testing Report** (HTML / TXT format)  
- **Screenshots** as evidence of identified vulnerabilities  
- **README.md** documentation  

---

## 📊 Results

The application was found to be **vulnerable to SQL Injection and Cross-Site Scripting (XSS)** attacks.  
Each vulnerability was successfully identified and validated using manual testing techniques.  
Detailed observations, evidence, and recommended mitigation strategies have been documented in the security report.
